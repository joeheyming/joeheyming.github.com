A tribute

This page is a loving tribute to onemillioncheckboxes.com — a shared grid of one million checkboxes built by Nolen Royalty, which captured the internet for a very strange and delightful summer in 2024.

The original is no longer live. This is a static-site re-creation of the same idea: no backend, no accounts. Writes go through a Google Form, reads come from a Google Sheet. Click any box and everyone else's page sees it flip.

Press i to see the grid as a 1000×1000 image — the rendering a group of teenagers in a Discord server used to hide URLs, QR codes, and pixel art inside the original. Press i again for the 24‑bit RGB view they invented for color, or esc to come back. Read the story.

Go read Nolen's blog — the engineering writeups about the original are great.
