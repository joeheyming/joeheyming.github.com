Imagine

Local image generator

This image generator needs WebGPU. The whole model runs on your device — no backend, no keys — and that needs WebGPU.

Supported: Chrome 113+, Edge 113+, Firefox 141+ (Windows/macOS), Safari 18+ (macOS). You'll also want a discrete GPU — running diffusion on an integrated GPU works but takes 5–10× longer per image.

📦

Install the local image model

This generator needs to install Janus-Pro 1B (~2.2 GB) into your browser cache. The model runs on your GPU — no backend, no API key, no third-party endpoint. After installing, each image takes about 20–60 seconds and works offline.

Stored in your browser's Cache Storage. You can clear it anytime from browser settings. First load takes a minute or two; everything after that runs from cache.

Type a prompt and hit Generate.

Pick a model under the prompt. SD-Turbo is fast and takes a seed. Janus-Pro is slower.
