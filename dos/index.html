How this works
  • This is MS-DOS only — not Windows or Steam .exe demos. Drop a classic DOS game zip (the player auto-detects the boot EXE).
  • Powered by js-dos v8 — DOSBox-x compiled to WebAssembly. Runs entirely in your browser.
  • Catalog games are pulled from Internet Archive's MS-DOS library on demand. Once cached they're instant and work offline.
  • Save files persist per game in IndexedDB on this device. Hit ← Back to catalog to snapshot the game state.
  • First-ever visit reloads once so the cross-origin-isolation service worker can take effect. After that, the player launches immediately.
