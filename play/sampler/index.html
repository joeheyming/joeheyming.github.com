How to play

  • Tap or click the keys, or use the Z – M and Q – U rows on a computer keyboard. [ and ] shift the octave.
  • Sound switches between the built-in instruments and any DirectWave file you load. A connected MIDI keyboard plays it too, with velocity.

About DWP support

This player supports monolithic DWP files, which contain their samples inside the preset. Presets that rely on separate sample folders, DWB banks, effects, and older formats are not supported yet.

DWP files can contain old local file paths. This app shows only sample filenames and never uploads anything.
