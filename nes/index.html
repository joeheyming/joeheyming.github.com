Controls & Hotkeys

Game Controls

  • Z - A button
  • X - B button
  • C - Select
  • V - Start
  • Arrow keys - D-Pad

Hotkeys

  • F5 - Quick Save
  • F9 - Quick Load
  • Space - Pause/Resume
  • R - Reset Game
