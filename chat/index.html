Local model

This chat needs WebGPU. The whole model runs on your device — no backend, no keys — and that needs WebGPU.

Supported: Chrome 113+, Edge 113+, Firefox 141+ (Windows/macOS), Safari 18+ (macOS). On Windows with a recent NVIDIA/AMD GPU, WebGPU should be on by default in Chrome/Edge — if it's not, the most common cause is hardware acceleration being disabled in browser settings.

📦

Install the local model

This chat needs to install Hermes-3 8B (~4.5 GB) into your browser. The full model runs on your device — no backend, no API key, no third-party LLM endpoint. After installing, chat is instant and works offline.

Stores in your browser's cache (OPFS). You can clear it anytime from browser settings. First load takes a minute or two; everything after that runs from cache.
