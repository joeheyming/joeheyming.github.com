Free browser IDE with on-device AI assistant

Code IDE is a browser-based code editor powered by Monaco (the same engine that runs VS Code) with a project file tree, tabs, Vim keybindings, Prettier format-on-save, a sandboxed JavaScript runner, side-by-side diff, and basic git integration. The optional AI assistant runs Hermes-3 locally via WebLLM on WebGPU — no API key, no backend, no third-party LLM endpoint. Files can be loaded from a real folder on disk via the File System Access API or from the Heyming OS virtual filesystem.
